Swiply permet aux étudiants de trouver un stage ou une alternance en swipant des offres, comme sur une application de rencontres. Cette version de démonstration tourne sans serveur : les offres viennent de fichiers JSON et vos actions restent dans votre navigateur. Les offres sont fictives : les entreprises citées n'ont aucun lien avec ce projet.
